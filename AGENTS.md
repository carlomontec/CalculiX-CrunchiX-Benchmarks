# Conventions for Contributors and Agents

This repository holds benchmark models, the runner, results and reports.
Solver source code, the build system and the official test suite belong in the
code repository, [CalculiX-CrunchiX-MultiSolver](https://github.com/carlomontec/CalculiX-CrunchiX-MultiSolver).
Showcase examples of CalculiX features do not belong here: a model is added
only to measure or verify solver behaviour.

## Workflow

- **Never commit or push without the maintainer's (Carlo's) explicit permission.**
- Propose larger changes (new top-level folders, new metadata fields, changed
  layout) before making them.
- All text in English.
- Keep the history clean: one commit per added study, report or benchmark run,
  with a message that says what was measured, for example
  `benchmarks(naca_blade): ultra-fine mesh on Ryzen 5 5600, Linux, v2.24-multisolver-0.2`.

## Folder rules

| Content | Folder |
|:---|:---|
| Verification of a release against official CalculiX | `releases/<release tag>/<topic>/` |
| A benchmark model | `models/<model>/` (deck, `remesh.py`, README with license) |
| One benchmark run | `results/<model>/<YYYY-MM-DD>_<machine label>_<mesh>/` |
| Test-suite report for an upstream merge | `upstream-merges/<YYYY-MM>/` |
| JSON export reports | `json-export/<YYYY-MM>_<topic>/` |
| Longer write-ups | `studies/<topic>/README.md` |

- `<model>` is the folder name under `models/` (for example `naca_blade`,
  `compressor_rotor`).
- `<machine label>` is `<cpu>_<os>` in lower case, for example
  `ryzen5-5600_linux`, `apple-m3_macos`. Never use host names or user names.
- `<mesh>` is the runner's `--level` with `_` replaced by `-`.

## Models and licenses

- Every model README states author and license. Models written for this
  repository: scripts GPL-2.0 (with an `SPDX-License-Identifier` line), decks
  and text CC BY 4.0.
- Third-party models keep their original license and get an attribution
  section naming the source, the author and the license. Copy them unchanged;
  put any change in a separate file or script. Example: `models/compressor_rotor`
  (Klaus Wittig, cgx examples, GPL-2.0-or-later).
- Do not add a model whose license is unknown.
- Meshes are generated by `remesh.py`, not committed.

## Files in a result folder

- `run.json`: **mandatory** in every result folder (benchmarks, reports,
  studies). Copy one of the same kind and fill every field.
- `results.json`: benchmark runs only; the runner's output, unchanged except
  that `metadata.system_profile.hostname` is replaced by the machine label.
- `REPORT.md`: reports; `README.md`: studies.
- Benchmark `README.md` files are generated. Do not edit them.
- Do not commit `.frd`, `.dat` or other raw solver output, meshes or
  binaries. Summaries only. The runner writes to `runs/`, which is ignored.
- No absolute paths, host names, user names or e-mail addresses in any file.

## run.json fields

| Field | Meaning |
|:---|:---|
| `kind` | `benchmark`, `report` or `study` |
| `title` | One line, shown in the index |
| `date` | `YYYY-MM-DD` of the run (`YYYY-MM` for studies) |
| `code` | `repository`, `ref` (tag or branch), `commit`, `version`, `note` |
| `machine` | `label`, `cpu`, `cores`, `ram_gb`, `os`, `compiler` |
| `build` | Per solver: BLAS library and build options |
| `model` | Benchmarks: `name`, `deck`, `analysis`, `mesh`, `nodes`, `elements`, `equations`, `source` (`models/<model>`) |
| `solvers`, `threads` | Benchmarks: what was run |
| `command` | The exact command(s) |
| `summary` | Reports and studies: the headline result, one or two sentences |
| `notes` | List of remarks |

Anything not recorded at run time is `null`. Never estimate or reconstruct a
value and present it as recorded; if a value is known from elsewhere, say so
in `note` or `notes`.

## After any change

```bash
python3 tools/build_index.py          # regenerate README tables
python3 tools/build_index.py --check  # must print nothing and exit 0
```

Check that relative links resolve and that links to the code repository point
at a tag or `main`, not at a temporary branch.
